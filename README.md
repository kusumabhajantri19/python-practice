# Python Fundamentals Practice

## Description
This repository contains a collection of Python programs created to practice and strengthen core programming concepts.  
It covers a wide range of beginner to intermediate topics, organized into structured folders.

## Topics Covered
- Algorithms  
- Arrays  
- Conditional Statements  
- Loops  
- Functions  
- Recursion  
- Strings  
- Lists and Tuples  
- Object-Oriented Programming (OOP)  
- Error and Exception Handling  
- Iterators and Generators  
- Decorators  
- Pattern Programs  
- Time-based Programs  

## Project Structure
Each folder represents a specific topic and contains related practice programs.

## Purpose
To build a strong foundation in Python programming through hands-on practice.

## Usage
Run individual Python files to understand different programming concepts.
